```bash
cd C:/Users/l/Documents/GitHub/game/通天入地
python tools/validate_project.py
"/c/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64_console.exe" --headless --path . res://tools/smoke_test.tscn
```

完整测试脚本：`tools/full_audit_runner.gd`（驱动入口 `tools/full_audit.tscn`）。脚本把每条 `ACTION` / `OBSERVE` / `PASS` / `FAIL` 写入 `logs/full_audit.log`，并把结构化结果写入 `logs/results.json`。

技能测试统一做法：将目标职业切为出战角色 → 清空干扰敌人 → 满蓝/重置冷却 → 按技能类型在有效范围内放置 3000 HP 木桩 → 施放技能 → 校验 MP 扣除、冷却进入、VFX 节点生成、技能专属效果（伤害/治疗/Buff/护盾/位移）。
