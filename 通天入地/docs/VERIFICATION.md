# 《通天入地》验证方案

> 目标：在不依赖人工判断的前提下先完成自动化回归，再用逐条手工用例覆盖表现层与交互层。
> 所有命令均在工程根目录 `/workspace/通天入地` 下执行。

---

## 1. 环境准备

### 1.1 安装 Godot 4.7.2（固定版本）

```bash
cd /tmp
curl -L --fail -o godot.zip \
  https://github.com/godotengine/godot-builds/releases/download/4.7.2-stable/Godot_v4.7.2-stable_linux.x86_64.zip
unzip -o godot.zip
chmod +x Godot_v4.7.2-stable_linux.x86_64
/tmp/Godot_v4.7.2-stable_linux.x86_64 --version
```

预期输出：

```
4.7.2.stable.official.ed1daf0bf
```

> 工程通过 `config/features=PackedStringArray("4.7.2", "GL Compatibility")` 与根目录 `.godot-version` 双重固定版本。其他 Godot 4.7.x 兼容，但仅在 4.7.2 上完成回归验证。

### 1.2 工程自检

```bash
cd /workspace/通天入地
python3 tools/validate_project.py
```

预期：

```
结果：PASS（0 错误，0 警告）
```

校验内容：
1. `project.godot` 主场景、11 个 Autoload 路径存在且未声明 `class_name`；
2. 所有输入动作齐全（含 `open_skill_tree`）；
3. `.gd` 全部使用 Tab 缩进、无 `emit_signalv` / `randi(a,b)` / `groups.add` / Camera2D `offset` 冲突；
4. `.tscn` 的 `ext_resource` / `sub_resource` 引用与 `load_steps` 一致；
5. JSON 可解析，16 职业各 6 技能、16 节点技能树、3 条专职，配方/任务/建筑引用的物品都存在；
6. 脚本内 `res://` 路径存在。

## 3. 手工验收用例

> 启动方式（有显示器）：
> ```bash
> /tmp/Godot_v4.7.2-stable_linux.x86_64 --path /workspace/通天入地
> ```
> 或使用 Godot 4.7.2 编辑器导入工程后按 `F5`。

### V-01 启动与主菜单

1. 启动游戏。
2. 观察标题「通天入地」、副标题、5 个按钮（新游戏 / 继续 / 通天塔试炼 / 设置 / 退出）。
3. 首次运行点「继续」，应提示无存档（或按钮为禁用态）。
4. 打开「设置」，拖动音量滑块、切换全屏，退出设置后重新进入，设置应保留。

**预期**：标题与按钮居中、中文字体正常、无脚本报错；设置写入 `user://settings.cfg`。

### V-02 新游戏初始状态

1. 点击「开始新游戏」。
2. 观察左上角 HUD：职业名、生命/法力条、金币 120、经验 0。
3. 观察技能栏 3 个技能与快捷键 1/2/3。
4. 按 `I` 查看背包：石头 ×8、木头 ×8、草药 ×4、治疗药水 ×2。

**预期**：主世界加载，角色出现在菱形地面，HUD 数值正确，无报错。

### V-03 移动与相机

1. 用 `W/A/S/D` 或方向键移动，角色沿等距方向行走。
2. 移动鼠标滚轮，画面缩放（0.6x–1.8x）。
3. 切换角色后相机平滑跟随新角色。

**预期**：移动方向稳定、无抖动；相机不越界抖动；缩放不影响 UI。

### V-04 普攻、伤害与掉落

1. 靠近史莱姆（绿色敌人）。
2. 点击左键或按空格。
3. 观察红色伤害数字、扩散特效、敌人血条下降。
4. 击杀后观察金币增加、经验增加、地面出现菱形掉落物。
5. 走近掉落物自动拾取，HUD/背包数量增加。

**预期**：伤害数字上浮淡出；掉落物可拾取；`enemy_died` 正确触发。

### V-05 技能、冷却与法力

1. 按 `1` 释放第一个技能，观察特效与敌人掉血。
2. 观察技能槽出现冷却倒计时，冷却结束前再按无效。
3. 连续释放高耗蓝技能，直到法力不足。
4. 法力不足时按技能：应有提示，且不进入冷却。

**预期**：8 种技能类型表现符合设计（范围/弹道/治疗/增益/护盾/连锁/区域/突进）。

### V-06 冲刺无敌

1. 面向敌人按 `Shift`。
2. 在冲刺瞬间穿过敌人攻击。

**预期**：短距离位移、0.9 秒冷却；冲刺期间不受伤。

### V-07 职业切换

1. 按 `Q` 切换到弓箭手，再按 `Q` 切换法师，按 `P` 返回。
2. 观察角色颜色、HUD 名称、技能栏变化。
3. 让当前角色受伤后切换，再切回，血量应保留。

**预期**：未出战角色隐藏且无碰撞；切换即时生效；进度独立。

### V-08 死亡与复活

1. 关闭攻击，站到敌群中直到生命归零。
2. 观察角色变灰、输入锁定。
3. 等待约 1.2 秒。

**预期**：在出生点复活，恢复 50% 生命；非 Roguelike 场景不结束游戏。

### V-09 资源采集

1. 走到发光的资源点（木头/石头/草药/铁矿/皮革）。
2. 按 `E`。
3. 观察提示「采集：xxx ×N」，背包数量增加，资源点变暗。
4. 等待 8 秒，资源点恢复高亮，可再次采集。

**预期**：采集消耗交互距离 76；资源点重生倒计时显示在头顶。

### V-10 合成

1. 按 `I` 打开背包，切到「合成」页。
2. 找到「铁锭」配方，确认材料不足时按钮禁用。
3. 采集/购买足够铁矿与煤，点击合成。
4. 观察材料扣除、铁锭入包、任务「铁匠的委托」进度 +1。

**预期**：15 条配方均可查询；合成触发 `item_crafted`。

### V-11 商店买卖

1. 打开背包，切到「商店」页。
2. 购买治疗药水：金币减少、药水入包。
3. 选中背包中的材料出售：金币增加、物品减少。
4. 金币不足时购买：提示且不扣物品。

**预期**：价格 = 物品价值，买卖即时刷新。

### V-12 装备

1. 在背包中选择武器/护甲/饰品，点击「装备」。
2. 观察攻击/防御数值变化。
3. 点击「卸下」，装备回到背包，属性回落。

**预期**：同一槽位替换时旧装备退回背包；属性实时重算。

### V-13 沙盒建造

1. 按 `B` 进入建造模式，右侧出现方块列表与造价。
2. 选择「石砖」，左键点击地面放置。
3. 观察材料扣除、菱形方块出现、可碰撞方块阻挡角色。
4. 右键点击该方块拆除，返还 50% 材料。
5. 在建造模式下点击 UI 面板，不应误放方块。
6. 按 `B` 退出建造模式，角色恢复攻击。

**预期**：网格对齐、无重叠、材料不足时提示；建造记录按场景保存。

### V-14 NPC、对话与任务

1. 走到铁匠（橙色 NPC，坐标约 170,130），按 `E`。
2. 逐行推进对话，关闭后任务追踪出现「清理史莱姆 0/5」。
3. 击杀 5 只史莱姆，任务完成，获得 80 金币 + 2 瓶治疗药水。
4. 与工匠对话接取「铁匠的委托」，合成 2 块铁锭后获得铁剑。
5. 与学者对话接取「向塔而行」，抵达第 2 层后获得 150 金币 + 塔钥。

**预期**：对话期间游戏暂停；任务进度实时更新；奖励入包/入账。

### V-15 通天塔与限时机关

1. 走到主世界右侧传送门（约 470,0），进入第 1 层。
2. 观察层标题「通天塔 · 第 1 层」、2 个机关、锁住的门、未启用的上层传送门。
3. 踩下第一个机关，观察 25 秒倒计时开始。
4. 在倒计时内踩下第二个机关。
5. 观察门消失、特效、金币奖励、上层传送门启用。
6. 进入上层传送门，抵达第 2 层。

**预期**：机关计数正确；超时则全部重置（见 V-17）。

### V-16 职业限定机关

1. 抵达第 2 层。
2. 用 `Q/P` 切到非法师职业，踩 0 号机关。
3. 观察提示「此机关需要『法师』职业」且机关不激活。
4. 切换到法师，再次踩下。

**预期**：职业判定基于 `CharacterData.class_id`；提示清晰。

### V-17 限时解谜失败与重试

1. 在第 1 层只踩 1 个机关。
2. 原地等待 25 秒（不要踩第二个）。
3. 观察提示「超时！机关已重置」，所有机关恢复未激活。
4. 重新踩两个机关，应能正常开门。

**预期**：倒计时归零触发重置；可无限重试。

### V-18 深渊与返回地面

1. 在第 1 层走到下方蓝色传送门（约 0,340）。
2. 进入后观察标题「深渊 · 第 1 层」（`floor_num = -1`）。
3. 继续向下到 -2 层，观察敌人属性增强。
4. 走到上层传送门（约 0,-360），返回 -1 → 0（地面）。

**预期**：正数层通天、负数层入地；0 层回到主世界；Roguelike 状态保持。

### V-19 Roguelike、词条与 BOSS

1. 主菜单点「通天塔试炼」，或从地面进入塔。
2. 观察 HUD 显示本轮种子、层数、词条。
3. 推进到第 3 层，应新增 1 条随机词条。
4. 推进到第 5 层，应出现 BOSS「塔卫 · BOSS」，血条与体型更大。
5. 在塔内死亡，观察本轮结束并返回主菜单，最高层记录更新。

**预期**：词条每 3 层、BOSS 每 5 层；死亡结束本轮。

### V-20 存档与读档

1. 在主世界采集、合成、放置一个建筑、接取一个任务。
2. 按 `Esc` 打开暂停菜单，点击「保存」。
3. 退出到主菜单，点「继续游戏」。
4. 检查：位置、金币、背包、装备、任务、建筑、层数是否恢复。
5. 再次暂停保存到同一槽位，确认覆盖成功。

**预期**：`user://saves/save_0.json` 存在；读档后场景与坐标一致；无重复建筑。

### V-21 手柄

1. 连接手柄，启动游戏。
2. 左摇杆移动、A 普攻、X/Y/RB 技能、LB 冲刺、B 交互、Back 背包、Start 暂停。
3. 观察 InputManager 自动识别为手柄模式。

**预期**：所有映射可用；UI 不因手柄输入错乱。

### V-22 触屏

1. 在触屏设备或启用触摸模拟的环境启动。
2. 左下虚拟摇杆拖动移动。
3. 右下按钮依次点击：普攻、技能、冲刺、交互、背包、建造。

**预期**：TouchControls 自动显示；按钮直接调用角色方法；不依赖键盘事件。

### V-23 音频降级

1. 不放置任何 `audio/` 素材启动游戏。
2. 战斗、采集、开门、切换职业。

**预期**：无报错、无卡顿；AudioManager 静默跳过缺失资源。

### V-24 分辨率与缩放

## 5. 已知限制

1. **音频资源为空**：`audio/` 目录未附带素材，AudioManager 会静默跳过。
2. **版本固定**：使用 Godot 4.7.2-stable，通过 `.godot-version` 与 `project.godot config/features="4.7.2"` 双重固定。
3. **触屏按钮布局固定 960×540**：在极端宽高比下需按 `canvas_items` 缩放，已验证 16:9。
4. **Roguelike 层数为程序化复用**：所有楼层共用 `tower_floor_1.tscn`，通过 `pending_floor` 生成内容，不是独立关卡文件。
5. **AI 素材为离屏生成**：原图带洋红键背景与水印，已用 `tools/` 脚本去水印、键色反解算抠图、无缝化处理；再生成同批素材需重跑该工具链。
6. **地面贴图存在可见重复**：草地贴图以 320px 为平铺周期，大场景下可见规律性斑块，可调 `draw_ground_texture()` 的 `tile_px` 缓解。

## 6. 故障排查

| 现象 | 排查/解决 |
| --- | --- |
| 启动报「场景不存在」 | 确认 `scenes/main.tscn`、`main_world.tscn`、`tower_floor_1.tscn` 存在；运行 `validate_project.py` |
| 中文显示为方块 | 安装 CJK 字体（如 Noto Sans CJK）；`GameManager._install_cjk_theme()` 会使用系统字体 |
| 无头运行报显示错误 | 使用 `--headless`；不要在有显示器环境外调用 `--editor` 以外的渲染 |
| 触屏按钮不显示 | 桌面默认鼠标模式；在触屏设备运行，或在编辑器启用「Emulate Touch From Mouse」 |
| 读档后角色位置异常 | 检查 `save_0.json` 的 `player_pos` 是否为 `"(x, y)"` 字符串；`_to_vector2` 会解析 |
| 建造方块不恢复 | 确认 `BuildManager.restore_scene()` 在关卡 `_ready` 中调用，且场景路径与保存时一致 |
| 存档目录 | Linux：`~/.local/share/godot/app_userdata/通天入地/saves/`；Windows：`%APPDATA%\Godot\app_userdata\通天入地\saves\` |
| 修改数据表后未生效 | 重新启动游戏；DataManager 仅在启动时加载 JSON |
| 地面贴图不显示（纯色） | 检查 `assets/ground/` 下贴图是否存在；`AssetLibrary` 的 `ground_` 分支必须 `substr(7)`，否则会解析成 `_grass.png` |
| 地面贴图拉伸变形 | `draw_polygon` 的 UV 是归一化坐标，必须按 `point / tile_px` 计算，并开启 `texture_repeat = TEXTURE_REPEAT_ENABLED` |
| 贴图出现洋红边 | 素材未做键色反解算抠图，用 `python3 tools/make_enemy_sprites.py` / `clean_magenta.py` 重跑 |
| 掉落物显示为黑方块 | 物品图标原图是 256² 深底方块，需用 `python3 tools/make_pickup_sprites.py` 转成透明精灵 |
| 主菜单背景出现"AI生成"水印 | 水印位于原图右下角，`python3 tools/make_menu_bg.py` 通过裁掉右下边缘条带规避 |
| 地面贴图有明显重复斑块 | `make_ground_tiles.py` 的 `reduce_blob_contrast()` 已把土斑压低对比；必要时调大 `strength` 参数重跑 |
